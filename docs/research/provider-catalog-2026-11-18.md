# Provider and model audit — November 18, 2026

Vellum ships 15 cloud adapters and two local adapters. The bundled models work as an offline starting point. Use `/model refresh <provider>` for the inventory exposed by a specific account, deployment or local server. A saved custom model ID can address a private deployment.

## Pricing and verification

Verification used official public documentation, model cards, mocked SDK requests, and the installed provider test suite. Organization entitlements, regional deployment availability, billed inference and provider-specific service tiers require a live account. The budget calculator applies the direct-provider prompt-size thresholds to the full request. Haiku 5.5 changes rates above 100,000 prompt tokens including cache tokens. A missing tier-specific cache price falls back to the published base cache price when available. Extended cache retention, service tiers and regional pricing can affect an invoice. Anthropic summaries can arrive in bursts and may be absent on turns with no visible thinking.

Vendor docs, publicly served documentation schemas and SDK wire fixtures were checked on 2026-11-18. Private entitlements, regional deployments, fine-tunes, custom proxies and paid inference need the operator's credentials. Only explicit retirement evidence is used for new automatic migrations.

The catalog, adapter constructors, configuration schema, onboarding choices, credential environment lookup and explicit refresh entry point were compared for all 17 provider IDs. Model-refresh and authentication autocomplete now enumerate these same supported IDs. The OpenRouter comparison used an unauthenticated public listing. Local request, cancellation and removal behavior was verified with simulated endpoints. No local model weights were downloaded or paid inference calls made.

OpenRouter exposed prompt-length pricing for 55 of the 387 chat routes, including 17 in the offline shortlist. Its schema applies a length override strictly above the threshold. For the four GPT-6.2 gateway routes, a 272,000-token prompt keeps the short rate and a 272,001-token prompt uses the long rate. Discovery keeps separate input, output, cache-read and cache-write rates, including overlapping rules in the order the gateway specifies. The three routes advertising time-of-day discounts use the published base rate for estimates. Actual routing and request-time discounts can change billed cost.
